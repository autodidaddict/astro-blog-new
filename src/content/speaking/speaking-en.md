I have been speaking at conferences for well over a decade, on everything from Scala and .NET microservices to WebAssembly, NATS, event sourcing, and agentic systems. This is a list of the public talks I could track down, newest first. Where a recording exists, the talk title links to it. Where it does not, the title links to the session page or abstract.

## 2025

- **[Agentic Inception - Use Agents to Build Agentic Systems](https://newyork.qcon.ai/presentation/newyork2025/agentic-inception-use-agents-build-agentic-systems)**\
  QCon AI New York, December 2025. Sponsored session for Akka. Using AI coding assistants to build a resilient, distributed, production-grade agentic system from scratch.
- **[Event Sourcing: The Backbone of Agentic AI](https://2025.dddeurope.com/speakers/kevin-hoffman/)**\
  DDD Europe, Antwerp, June 2025. Sponsored talk for Akka. Why event sourcing is the foundational pattern for agentic systems that need perfect recall, auditability, and coordination between agents.

## 2024

- **[Nothing but NATS - Going Beyond Cloud Native](https://www.youtube.com/watch?v=ypsAus_OBmo)**\
  KubeCon + CloudNativeCon North America, Salt Lake City, November 2024. With Byron Ruth. How NATS alone can provide the compute, storage, and connectivity for applications that run from the cloud to the edge. [Session details](https://kccncna2024.sched.com/event/1hoyU) and [slides](https://hosted-files.sched.co/kccncna2024/c6/KubeCon%202024%20-%20Nothing%20but%20NATS.pdf).
- **[Introducing Nex, the NATS Execution Engine](https://www.youtube.com/watch?v=EfxtiKMnoyQ)**\
  RethinkConn, Synadia's virtual NATS conference, January 2024. A live demo of the Nex technology preview.

## 2023

- **[Bringing Cloud Native WASM to the Mainstream with the WASM Working Group](https://www.youtube.com/watch?v=b1675UWMLas)**\
  KubeCon + CloudNativeCon North America, Chicago, November 2023. Maintainer track, with Shivay Lamba. An introduction to the CNCF WebAssembly Working Group, its goals, and how to contribute. [Session details](https://kccncna2023.sched.com/event/1RQZf/bringing-cloud-native-wasm-to-the-mainstream-with-wasm-working-group-shivay-lamba-meilisearch-kevin-hoffman-cosmonic).
- **[Distributed Event Sourcing with wasmCloud](https://www.youtube.com/watch?v=llIiUYocYcw)**\
  KubeCon + CloudNativeCon Europe, Amsterdam, April 2023. Building aggregates, projectors, notifiers, injectors, and process managers as WebAssembly components and assembling them into a scalable event-sourced system. [Session details](https://kccnceu2023.sched.com/event/1Hycy/distributed-event-sourcing-with-wasmcloud-kevin-hoffman-cosmonic) and [demo code](https://github.com/autodidaddict/kubecon2023).
- **[Zero Trust in the Cloud with WebAssembly and wasmCloud](https://www.youtube.com/watch?v=70Ud9kc8J7w)**\
  CloudNativeSecurityCon North America, Seattle, February 2023. Combining WebAssembly's sandbox isolation with cryptographic signatures and a verifiable capability model to run untrusted code with confidence. [Session details](https://cloudnativesecurityconna23.sched.com/event/1FV4N/zero-trust-in-the-cloud-with-webassembly-and-wasmcloud-kevin-hoffman-cosmonic).

## 2022

- **[In Production with Elixir, Rust, and WebAssembly](https://www.youtube.com/watch?v=l0QS_iXlQto)**\
  ElixirConf US, Aurora, Colorado, September 2022. Running a Phoenix cluster with a GraphQL API alongside a user-installable Elixir application that joins a peer network executing WebAssembly.
- **[WebAssembly - The Future of Distributed Computing](https://www.youtube.com/watch?v=TVIIH_govGk)**\
  Craft Conference, Budapest, June 2022. Why WebAssembly's security, portability, size, and speed make it the ideal deployment unit for loosely coupled code outside the browser. [Speaker page](https://craft-conf.com/2022/speaker/KevinHoffman).

## 2021

- **[Elixir, WebAssembly, and Rust - The Ultimate Hybrid](https://www.youtube.com/watch?v=7Lj6ATt_2jY)**\
  ElixirConf EU, Warsaw, September 2021. The journey from a pure Rust wasmCloud host runtime to a Rust and Elixir/OTP hybrid, and what that enabled. [Talk page](https://www.elixirconf.eu/talks/elixir-webassembly-and-rust-the-ultimate-hybrid/).
- **[From Napkin to the Cloud: A WebAssembly Journey](https://www.youtube.com/watch?v=N9tj9ukFNig)**\
  Cloud Native Wasm Day Europe, co-located with KubeCon + CloudNativeCon Europe, May 2021. Taking an application from concept to production with polyglot actors in Rust and Go on wasmCloud. [Session details](https://cloudnativewasmeu21.sched.com/event/iOcs/from-napkin-to-the-cloud-a-webassembly-journey-kevin-hoffman-capital-one) and [slides](https://hosted-files.sched.co/cloudnativewasmeu21/a5/From%20Napkin%20to%20the%20Cloud%20A%20WebAssembly%20Journey.pdf).

## 2020

- **[Going Containerless with WebAssembly](https://www.youtube.com/watch?v=4jOlgsg6DhQ)**\
  KubeCon + CloudNativeCon Europe, August 2020. A Rust host runtime that dynamically and securely binds zero-trust WebAssembly functions to capabilities like message brokers and key-value stores. [Session details](https://kccnceu20.sched.com/event/Zer1/going-containerless-with-webassembly-kevin-hoffman-capital-one).
- **[Building a Containerless Future with WebAssembly](https://www.youtube.com/watch?v=vqBtoPJoQOE)**\
  WebAssembly Summit, Google, Mountain View, February 2020. A look at a future where WebAssembly modules are the unit of immutable deployment in the cloud, at the edge, and on embedded devices. [Slides](https://slides.com/autodidaddict/containerless-future) and [InfoQ coverage](https://www.infoq.com/news/2020/05/webassembly-summit-containerless/).

## 2019

- **[WebAssembly, Serverless, and the Cloud](https://kccncosschn19eng.sched.com/event/NrpR/webassembly-serverless-and-the-cloud-kevin-hoffman-capital-one-bank)**\
  KubeCon + CloudNativeCon + Open Source Summit China, Shanghai, June 2019. The back-end and cloud use cases for WebAssembly, and how to load, execute, and verify the provenance of WebAssembly code in the cloud.
- **[WebAssembly with Rust](https://www.youtube.com/watch?v=YDQICTKlr9g)**\
  Rust Latam, Montevideo, March 2019. A demo-heavy tour from WebAssembly basics through JavaScript integration to hosting modules in Rust applications, ending with hot-swapping modules that drive LEDs on a Raspberry Pi. [Conference page](https://2019.rustlatam.org/).

## 2018

- **[WebAssembly 101](http://qconnewyork.com/ny2018/ny2018/speakers/kevin-hoffman.html)**\
  QCon New York, June 2018. Sponsored session. What WebAssembly is and is not, how it interoperates with JavaScript in the browser and other hosts, and how to generate fast, safe modules with Rust.
- **[Building Reactive Microservices with .NET Core](https://www.youtube.com/watch?v=bGdar01KNzg)**\
  Cloud Foundry Summit North America, Boston, April 2018. Designing around distributed transactions with event sourcing, CQRS, and eventual consistency, with ASP.NET Core services consuming Kafka events. I also co-taught the full-day Cloud-Native .NET training at the same summit with Chris Umbel and Alex Sartan. [Session details](https://cfna18.sched.com/kevin818).
- **[Designing Reactive Microservices with ASP.NET Core](https://web.archive.org/web/20190718063938/https://conferences.oreilly.com/software-architecture/sa-ny-2018/public/schedule/speaker/244697)**\
  O'Reilly Software Architecture Conference, New York, February 2018. Event sourcing, CQRS, and eventual consistency with ASP.NET Core, Kafka, and Postgres.

## 2017

- **[Building Microservices with ASP.NET Core](https://web.archive.org/web/20200813090326/https://conferences.oreilly.com/software-architecture/sa-eu-2017/public/schedule/speaker/244697)**\
  O'Reilly Software Architecture Conference, London, October 2017. Using ASP.NET Core to build immutable releases with Docker, handle configuration, security, and data access, and deliver continuously in the cloud.
- **[Beyond the 12 Factor Application](https://web.archive.org/web/20191105115238/https://skillsmatter.com/legacy_profile/kevin-hoffman-cloudnative)**\
  Cloud Native London, September 2017. What it actually means to be cloud native, and the key factors that make an application ready for the cloud.
- **The Way of the Cloud**\
  Beijing, September 2017. Cloud native patterns, the fifteen factors, and the team philosophy that Dan Nemeth and I call the Way of the Cloud (云道).
- **[Cloud Native Go](http://qconnewyork.com/ny2017/ny2017/presentation/cloud-native-go.html)**\
  QCon New York, June 2017. Sponsored session. Patterns, practices, and sample code for building microservices in Go, from routing and middleware to security, configuration, testing, and continuous deployment. [Slides](https://github.com/autodidaddict/cng-presentation).
- **[Supporting Your Microservices with Redis - 3 Languages, 3 Scenarios](https://web.archive.org/web/20170531002000/http://redisconf.com/)**\
  RedisConf, San Francisco, June 2017. Three real-world, in-production scenarios for supporting microservices with Redis, with code in C#, Go, and Rust.
